### Shared focus ring disappears into light venue and travel surfaces

The global focus treatment uses a 3px `#e2a840` outline with a 4px offset (`styles.css:54-56`). This is a **confirmed** accessibility issue on the backgrounds introduced by the same change: the outline measures approximately 2.12:1 against white venue cards, 2.00:1 against `#fbf8f1`, 1.87:1 against `#f5f0e6`, and 1.59:1 against the travel section’s `#e7ded0`, all below the 3:1 contrast expected for a keyboard focus indicator. Map links, transit links, and copy-address buttons can therefore receive focus without a sufficiently distinguishable indicator on those surfaces. Use a darker focus color on light sections or a two-color focus ring that works across both light and dark surfaces.

The keyboard styling test only asserts that `:focus-visible` appears somewhere in the stylesheet (`tests/site.test.js:111-118`). That assertion cannot distinguish a high-contrast focus treatment from the current low-contrast one, even though the adjacent test now calculates contrast correctly for eyebrow text. Extend the same color-pair approach to the focus indicator and its light backgrounds so this regression becomes enforceable.

</details>
